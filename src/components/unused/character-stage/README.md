# Character Stage (Archived)

This is an archived interactive typography experiment. A small SVG character walks to clicked destinations, uses a ladder to change height, and redirects surrounding copy as it moves.

The component uses `@chenglou/pretext` to measure text and calculate each displayed line without relying on DOM layout measurements. It was previously exposed at `/experiences/character-stage` and as a home-canvas card.

It is intentionally not imported or routed. Keep it here only as a reference for future text-flow or character-rigging experiments. If it is restored, add `@chenglou/pretext` back to the project dependencies first.
